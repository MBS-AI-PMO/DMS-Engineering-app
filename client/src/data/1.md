## Task 2 — Seed Metals Data into DB · Dynamic Pages · Slug-Based URLs

### 2a — Database Seeding
- Create a seed script (e.g., `seed_metals.py` or a management command) that inserts **all metals data** into the database with correct field mappings.
- Each metal must be assigned to its proper category.
- Seed script must be idempotent (safe to run multiple times without duplicates).

### 2b — Dynamic Data Fetching
- Replace all hardcoded/static metals data on the frontend with API calls to the backend.

### 2c — Slug-Based URLs

- Generate slugs during seeding and on every create/update.

- Update all frontend links, API calls, and backend route handlers accordingly.

### Acceptance Criteria
- [ ] All metals exist in the DB after running the seed script.
- [ ] No page shows hardcoded metal data.
- [ ] All metal URLs use slugs — no raw integer IDs in any URL.
- [ ] Slug uniqueness is enforced at the DB level.

## Task 3 — Full Admin Dashboard

> **Routing:** The Admin Dashboard must be served on the **same domain** under the `/admin` URL prefix.
> Example: `https://yourdomain.com/admin`, `https://yourdomain.com/admin/metals`, `https://yourdomain.com/admin/categories`, etc.
> - All admin routes must be nested under `/admin/*`.
> - The login page for admins should be at `/admin/login`.
> - After successful login, redirect to `/admin/dashboard` (or `/admin`).
> - Non-admin users who land on any `/admin/*` route must be redirected to `/admin/login`.
> - The public site routes (`/`, `/metals/`, `/faqs/`, etc.) must remain completely unaffected.

Build a fully functional, polished Admin Dashboard. Use best-in-class UI with smooth, purposeful animations (e.g., Framer Motion / CSS transitions). No janky or excessive animations — every animation must serve a UX purpose.

## Task 7 — Metal Detail Page: 5 Tabs, Fully Configurable

Each metal detail page (both on the public site and in the admin) must have **5 tabs**. Each tab is managed independently.

### Requirements
- Analyze the existing website to identify the current 5 tabs and their fields.
- Each tab's fields must be editable independently in the admin edit view.
- Some fields within tabs are **optional** — mark them clearly and do not show them on the public page if empty.
- Optional fields that are empty should be hidden on the public page (not shown as blank/empty).
- In the admin edit view, optional fields should be toggleable (show/hide toggle or greyed out).
- Adding a **custom field** (from Task 3.1) should allow the admin to assign it to a specific tab.
- Each tab must have its own save/update action (or the overall save applies per-tab changes globally — document chosen approach).

### Acceptance Criteria
- [ ] All 5 tabs render correctly on the public metal detail page.
- [ ] Empty optional fields are hidden on the public site.
- [ ] Admin can configure each tab's fields independently.
- [ ] Custom fields can be assigned to a chosen tab.

## Task 9 — UI/UX: Best-in-Class Design with Purposeful Animations

Apply across the **entire** project — both public site and admin dashboard.

### Design Goals
- Clean, modern, professional aesthetic.
- Consistent design system: typography scale, color palette, spacing scale, component library.
- Fully responsive: mobile, tablet, desktop.
- Dark/light mode support (if feasible — bonus).

### Animation Guidelines
- Use **Framer Motion** (React) or CSS transitions — no third-party animation-heavy libraries unless necessary.
- Animate: page transitions, modal open/close, accordion expand/collapse, table row actions, toast notifications, loading skeletons.
- Keep animations under **300ms** for micro-interactions, **500ms** max for page-level transitions.
- No animations that block user interaction or cause layout shift.

### Specific Components to Polish
| Component | Animation |
|-----------|-----------|
| Sidebar / Navbar | Smooth collapse/expand |
| Modals & Drawers | Fade + slide in |
| Table rows | Subtle fade on add/remove |
| Buttons | Press scale + ripple |
| Dropdowns | Smooth height expand |
| Notifications/Toasts | Slide in from corner |
| Page routes | Fade or slide transition |
| Accordions (FAQ) | Smooth height animation |
| Loading states | Skeleton shimmer |
