1. Overview - How It All Connects

When a user uploads a 3D model (STEP) or 2D drawing (DXF), the system extracts geometric data and calculates a real-time price. The total per-unit cost is composed of four main components:

Total Unit Price = (Material Cost + Production Cost + Additional Services Cost) x (1 + Markup%) - Quantity Discount
1
File Upload - User uploads STEP or DXF file. Backend extracts dimensions (length, width, thickness), perimeter, pierce count, hole data, and bend information.
↓
2
User Configuration - User selects: Production Service (e.g. Laser Cutting), Metal (e.g. 6061 T6 Aluminum), Thickness (from available stock), and Additional Services (Bending, Powder Coating, Taps, Hardware).
↓
3
Pricing Calculation - Frontend sends all parameters to POST /api/pricing/calculate. Backend computes Material + Production + Additional Services costs.
↓
4
Markup & Discounts - Global markup percentage (from Admin Settings) is applied. Quantity-based discount tiers are checked and applied.
↓
5
Display - Final per-unit and total prices shown to user in real-time. Breakdown includes all cost components.

2. Material / Sheet Cost

Material cost represents the raw metal consumed per part, calculated using a nesting model that determines how many parts fit on a standard sheet.

2.1 Standard Sheet Size

ParameterValue
Sheet Length120 inches (10 ft)
Sheet Width60 inches (5 ft)
Edge Buffer0.125 inches (distance from sheet edge)
Part Buffer0.0625 inches (gap between parts)
Kerf Width0.01 inches (laser cut width)

2.2 Nesting Formula

Usable Length = 120 - 2 x 0.125 + 0.0625 = 119.8125"
Usable Width = 60 - 2 x 0.125 + 0.0625 = 59.8125"

Buffered Part Length = Part Length + 0.0625 + 0.01
Buffered Part Width = Part Width + 0.0625 + 0.01

Parts Per Sheet = floor(Usable Length / Buffered Part Length) x floor(Usable Width / Buffered Part Width)

Material Cost Per Unit = Sheet Cost (5x10) / Parts Per Sheet

2.3 Sheet Cost Lookup

The system looks up the sheet cost from the sheet_cost_rates table using this priority:

  1. Exact match: Find a row where the metal's family matches AND the thickness value matches the selected stock thickness for that gauge.
  2. Closest thickness: If no exact match, find the closest thickness entry in the same family.
  3. Generic fallback: If no family match at all, use the "generic" family rates.
Admin Configuration: Sheet cost rates are managed via Admin Panel. Each entry has: Material Family, Thickness (single value per gauge), Gauge (optional), and Sheet Cost for a 5x10 ft sheet.

3. Laser Cutting Cost

Laser cutting cost is time-based, combining setup time (amortized over quantity) and per-part runtime calculated from perimeter and pierce count.

3.1 Core Formula

Laser Cost Per Unit = (Hourly Rate x Setup Hours / Quantity) + (Hourly Rate x Runtime Hours)

Where:
  Runtime Hours = (Perimeter_mm / Cut Rate_mm/s) / 3600 + (Pierce Count x Pierce Time_s) / 3600

3.3 Input Data (from model analysis)

  • Total Perimeter (mm) - Sum of all cut edge lengths from the flat pattern. For STEP files this comes from the unfolding engine; for DXF files from path analysis.
  • Pierce Count - Number of separate cut starts. Equals the number of holes + 1 (for the outer profile). Minimum value is 1.
Fallback: If perimeter data is unavailable, the system estimates it as: (Length + Width) x 2 x 25.4 (envelope perimeter in mm).

3.4 Laser Rate Lookup

The system queries the laser_cut_rates table by:

  1. Match by metal's material family AND closest thickness
  2. If no family match, fall back to "generic" family
  3. If no database match at all, use fallback defaults from service config
Warning: If the selected thickness exceeds 0.376 inches, the system flags a warning that the material may exceed laser cutting capability.

4. Bending Cost

Bending cost uses a labor-time model with per-bend runtime categorized by bend size, plus setup time based on unique bend configurations.

4.1 Core Formula

Bending Cost Per Unit = (Total Setup Cost / Quantity) + (Machine Time Per Unit x Labor Rate / 3600)

Where:
  Total Setup Cost = Unique Feature Count x Setup Time Per Unique x Labor Rate
  Machine Time Per Unit = Sum of runtime seconds for each bend

4.2 Bend Classification

Each bend detected from the 3D model is classified by its length:

CategoryConditionDefault Runtime
Small BendLength < 8 inches15 seconds
Medium Bend8" ≤ Length < 20"15 seconds
Large BendLength ≥ 20 inches20 seconds
HemBend angle within 5 degrees of 180 degrees20 seconds
Why there is no "small bend threshold": Only two thresholds are needed to divide bends into three length buckets. "Small" is the implicit default — any bend shorter than the Medium Bend Threshold (8") falls into it. There is no minimum length below which a bend is rejected or priced differently, so no small threshold is required. Hems are identified by angle (≈180°) and override the length-based classification entirely.

4.3 Unique Feature Tracking

The system identifies unique bend configurations based on the combination of:

  • Bend radius
  • Bend angle
  • Bend type (hem vs standard — a hem is any bend within 5 degrees of 180)

Each unique configuration requires its own tooling setup. Setup time = 0.25 hours per unique feature (default).

Unique features: 3 (small, medium, large)

5. Powder Coating Cost

Powder coating uses an oven utilization model that calculates how many parts fit per oven batch, then divides the batch cost across all parts.

5.1 Core Formula

Powder Coating Cost Per Unit = (Setup Charge + Number of Batches x Batch Cost) / Quantity

Where:
  Setup Charge = (Setup Time minutes / 60) x Shop Rate
  Parts Per Batch = best of two hanging orientations
  Number of Batches = ceil(Quantity / Parts Per Batch)

5.2 Oven Nesting (Two Orientations)

Orientation 1:
  Columns = floor(Oven Width / (Part Width + 6"))
  Rows = floor(Oven Length / (Part Thickness + 24"))
  S1 = Columns x Rows

Orientation 2:
  Columns = floor(Oven Length / (Part Width + 6"))
  Rows = floor(Oven Width / (Part Thickness + 24"))
  S2 = Columns x Rows

Parts Per Batch = MAX(S1, S2)
Hanging Logic: Parts are hung on racks in the oven. The 6" gap is clearance between parts side-by-side. The 24" accounts for the rack/hook mechanism height plus the part's hanging dimension.

5.4 Color / Finish Options

Powder coating colors are configured as service_options (JSONB array on the service record). Each option can have:

  • Name (e.g. "Matte Black", "Gloss White")
  • Color hex code (for UI display)
  • Price (surcharge - for non-powder finishes like anodizing)

For powder coating specifically, the batch cost model already includes the coating cost. For other finish types (e.g. anodizing), the option's price is added as a direct surcharge per unit.

6. Additional Services (Taps, Hardware, Countersinks)

These are manually priced per hole. The user selects specific holes from the 3D model and assigns operations:

Tap Cost = Sum of (price per tap x count) for each selected tap type
Hardware Cost = Sum of (price per insert x count) for each selected hardware type
Countersink Cost = Sum of (price per countersink x count) for each selected type

Prices for each tap/hardware/countersink option are configured via admin as service options with fixed per-unit prices.

7. Global Markup

Unit Total (before markup) = Material Cost + Production Cost + Additional Services Cost

Unit Total (after markup) = Unit Total x (1 + General Markup% / 100)

The General Markup percentage is stored in the site_settings table under the key 'general_markup'. Default is 10%. It is applied to all cost components uniformly.

Admin Control: The markup percentage can be changed from the Admin Settings panel. It applies globally to all orders.

8. Quantity Discounts

Discount Amount = Unit Total x (Discount Percent / 100)

Final Unit Price = MAX(0, Unit Total - Discount Amount)
Total Order Price = Final Unit Price x Quantity

8.1 Tier Matching

Discount tiers are stored in the quantity_discounts table. Each tier has:

  • quantities - A JSON array of quantity values (e.g. [50, 100])
  • discount_percent - The discount to apply (e.g. 15%)
  • is_active - Whether this tier is enabled

The system sorts tiers by highest quantity first, then matches the first tier where the order quantity is found in (or exceeds) the tier's quantity list.

10. Complete Pricing Example

A user uploads a sheet metal part with the following properties:

Given:

  • Part dimensions: 12" x 8" (flat pattern)
  • Metal: 6061 T6 Aluminum, 0.125" thick
  • Cut perimeter: 2,000 mm
  • Pierce count: 10 (9 holes + 1 outer profile)
  • 3 bends: 2 small (5"), 1 medium (10")
  • Powder coating (Matte Black)
  • Quantity: 25
  • Sheet cost (5x10 ft): $280
  • Cut rate: 80 mm/s, Pierce time: 0.4s
  • General Markup: 10%
Step 1: Material Cost
Buffered Part: 12.0725" x 8.0725"
Parts per sheet: floor(119.8125 / 12.0725) x floor(59.8125 / 8.0725) = 9 x 7 = 63
Material Cost = $280 / 63 = $4.44

Step 2: Laser Cutting Cost
Runtime = (2000 / 80 / 3600) + (10 x 0.4 / 3600) = 0.00694 + 0.00111 = 0.00806 hrs
Setup = 0.30 hrs (thin material)
Laser Cost = ($100 x 0.30 / 25) + ($100 x 0.00806) = $1.20 + $0.81 = $2.01

Step 3: Bending Cost
Unique features: 2 (small, medium)
Setup = 2 x 0.25 x $85 = $42.50
Machine time = (2 x 15) + (1 x 15) = 45 seconds
Bend Cost = ($42.50 / 25) + (45 x $85 / 3600) = $1.70 + $1.0625 = $2.76

Step 4: Powder Coating
Setup = (15 / 60) x $38 = $9.50
S1 = floor(90 / 14) x floor(160 / 24.125) = 6 x 6 = 36 parts/batch
Batches = ceil(25 / 36) = 1
Coating Cost = ($9.50 + 1 x $150) / 25 = $6.38

Step 5: Subtotal & Markup
Subtotal = $4.44 + $2.01 + $2.76 + $6.38 = $15.59
After Markup = $15.59 x 1.10 = $17.15

Step 6: Final Price
Final Unit Price = $17.15 (assuming no quantity discount tier matched)
Total Order Price = $17.15 x 25 = $428.75
